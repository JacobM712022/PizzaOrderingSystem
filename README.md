# PizzaOrderingSystem
CS492 Pizza Ordering System for Colorado Pizza

# How to Run This Project
1. Install Python:
- Make sure Python is installed on your computer.
  - Download it here:
https://www.python.org/downloads/
- When installing, check the box that says:
“Add Python to PATH”

2. Install Git:
- Git lets you download and update the project easily.
  - Download Git here:
https://git-scm.com/downloads
- Install it with the default settings.

3. Download the Project (Clone the Repository)
- Pick a folder on your computer where you want the project to live
(Desktop, Documents, anywhere is fine)
- Right‑click inside that folder
- Choose “Open in Terminal” or “Open Git Bash here”
- Type this command and press Enter:
  - git clone https://github.com/YOUR_USERNAME/PizzaOrderingSystem.git
    - *This creates a new folder called PizzaOrderingSystem with all the project files inside it.*

4. Open the Project
- Open the new PizzaOrderingSystem folder in your code editor
(VS Code, PyCharm, Spyder, etc.)

5. Install Flask
- Open a terminal inside the project folder and run:
  - pip install flask
   - *This installs the only library the project needs.*

6. Run the App
- Inside the project folder, run:
  - python app.py

- You should see something like:
  - Running on http://127.0.0.1:5000/

- Open that link in your browser to use the website.

7. Making Changes
- If you want to make updates:
i.e. Edit the files normally, 
Save your changes, 
Open the terminal, etc.
Run these commands:
- git add .
- git commit -m "Describe what you changed"
- git push

Changes will upload to GitHub so the we can see them.

8. Getting the Latest Updates
- Before you start working each day, run:
  - git pull
    - *This downloads any new changes that have been made.*
